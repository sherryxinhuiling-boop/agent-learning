# Agent 的三个组成部分

一个 AI Agent 由三样东西构成：**模型、工具、循环**。缺任何一样，它都还不是 Agent。

## 模型

模型负责决策：下一步该做什么、该调用哪个工具、什么时候可以停下来回答。它是 Agent 的大脑。

需要强调的是，模型本身**不执行任何操作**。它只会输出文字或结构化的调用请求。真正动手的是你的代码。

## 工具

工具是模型可以请求调用的函数。比如网页搜索、读写文件、执行代码、查询数据库。

工具的定义需要包含三部分：名称、用途说明、参数结构。用途说明写得越清楚，模型选错工具的概率越低。

一个常见的误区是给 Agent 塞几十个工具。工具越多，模型的选择空间越大，选错的概率也越高。实践中的经验是：**单个 Agent 配 3 到 8 个工具比较合适**，超过这个数量就该考虑拆分职责。

## 循环

循环是让 Agent 区别于普通聊天机器人的关键。普通调用是「问一次、答一次」，而 Agent 是：

1. 把当前状态发给模型
2. 模型决定下一步动作
3. 执行这个动作，把结果加回状态
4. 回到第 1 步，直到模型认为任务完成

这个循环可能只跑一轮，也可能跑几十轮。**必须有明确的终止条件**，否则会陷入无限循环并持续消耗 token。

实践中通常设置三重保护：最大轮数上限、最大 token 预算、以及超时时间。

## 判断一个系统是不是 Agent

问自己两个问题：

- 它能不能自己决定**下一步做什么**？
- 它能不能**根据执行结果调整**后续动作？

两个都是「能」，它才是 Agent。如果步骤是写死的，那只是一个工作流，不是 Agent。
